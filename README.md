## About

I'm a **Tech Lead at [neri](https://neri.care)**, a health tech company building care coordination infrastructure. I have **4+ years** of experience building web and mobile products in corporate environments.

Right now I'm leading the rebuild of our engineering team around **AI in the development lifecycle**, using **Spec-Driven Development** as the foundation. I introduced **OpenSpec** to our main project to support that shift.

As Tech Lead, I'm the technical reference for engineering and product. I plan features and make sure they ship, design integrations between large systems, set up monitoring at the platform's critical points, and resolve complex database performance incidents.

- **Software Engineering** — event-driven architecture, microservices, observability, integration across distributed systems
- **AI Engineering** — multi-agent architectures, prompt orchestration, spec-driven workflows, LLM integrations
- **Full Stack** — React, Next.js and React Native on the client; Node.js, NestJS and Spring Boot on the server
- **Cloud** — AWS (EC2, ECS Fargate, S3, RDS, Lambda, SNS), CI/CD with GitHub Actions
- **Quality** — background in QA engineering, test automation and DevOps from international projects (EMEA & LATAM)

**Open To** — conversations on AI-driven software engineering, Spec-Driven Development, health tech, and technical leadership.
